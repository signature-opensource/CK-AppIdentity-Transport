# CK.AppIdentity.Cris.AuthCenter

**Deprecated: renamed `CK.AppIdentity.AuthCenter`** ([documentation](https://github.com/signature-opensource/CK-AppIdentity-Transport/blob/stable/CK.AppIdentity.AuthCenter/README.md)).

This package is a tombstone: it has no code, and a project that depends on it (directly or through another package)
fails to build with the `CKDEPRECATED` error. Its `.Local`, `.Remote`, `.Oidc` and `.Passkey` packages and
`CK.Testing.AppIdentity.Cris.AuthCenter` are renamed the same way, and the namespace is now `CK.AppIdentity.AuthCenter`:
see the [migration guide](https://github.com/signature-opensource/CK-Stack/blob/main/Docs/Migrations/v2026.282-to-explo-cris-auth.md).
