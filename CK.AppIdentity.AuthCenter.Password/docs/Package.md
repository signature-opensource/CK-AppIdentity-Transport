The password login of the CK Authentication Center: the "Password" option of the Authentication Center, the "Basic" (a user name and a password) scheme family.

It holds the family only (the scheme, no account creation): the login provider is the backend's, referenced apart.
`"AuthCenter": { "Password": false }` turns the scheme off for a party.

See the [README](https://github.com/signature-opensource/CK-AppIdentity-Transport/blob/stable/CK.AppIdentity.AuthCenter.Password/README.md).
